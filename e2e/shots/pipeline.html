How Here Lies works

One photo, two calls to Gemma 4 on this laptop, and one check in plain Go code.

1 · Look
Gemma 4 sees the photo

Lists what it can see, injuries first.

d1 damage charred surface
d2 wear discoloration
d3 feature square shape

→
2 · Gate
plain code

A person, a pet or a healthy plant gets a still-alive notice. A photo it cannot make out gets a request for a better one.

Everything else goes on.

→
3 · Write
Gemma 4, text only

Never sees the photo. Writes the obituary from the list and cites an id for every physical sentence.

"cause": … "d1"

→
4 · Check
plain code

Every cited id must exist. The cause must be damage or wear. Lengths must fit.

Fail: one rewrite, then repair from the list.

The model may invent a name. It may not invent a scratch.
